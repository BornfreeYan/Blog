JavaScript 是一种轻量级、解释型、面向对象的脚本语言。它主要被设计用于在网页上实现动态效果，增加用户与网页的交互性。

### 导入方式

在网页开发中，JavaScript 可以通过多种方式导入到 HTML 文档中。以下是几种常见的 JavaScript 导入方式：

1. `内联方式（Inline）`：在 HTML 文件中直接嵌入 JavaScript 代码，放置在 `<script>` 标签内，通常位于文档的 `<head>` 或 `<body>` 部分。

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta http-equiv="X-UA-Compatible" content="IE=edge">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>内联样式</title>
</head>
<body>
<script>
    console.log('Hello');
</script>
</body>
</html>
```

2. `外部引入方式（External）`：将 JavaScript 代码保存在独立的外部文件中，通过 `<script>` 标签的 src 属性引入。

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>External JavaScript</title>
    <!-- 引入外部JavaScript文件 -->
    <script src="myscript.js"></script>
</head>
<body>

</body>
</html>
```

外部 JavaScript 文件 `myscript.js` 的内容：

```
console.log('Hello');
```

### `<script>` 的位置与 `defer`

**结论**：`<script>` 写在 `<head>` 里又没加 `defer`，脚本会在 DOM 解析完成之前执行——此时 `querySelector` 拿到的是 `null`，后续操作全报错。这是原生 JS 的第一个坑。两种解法：

1. 把 `<script>` 放到 `<body>` 末尾（执行时 DOM 已就绪）；
2. 保留在 `<head>`，加 `defer`：浏览器先解析完 DOM，再按脚本出现顺序依次执行。

```html
<head>
    <!-- 按顺序执行：先 api.js，再 app.js -->
    <script src="./js/api.js" defer></script>
    <script src="./js/app.js" defer></script>
</head>
```

> `defer` 与 `async` 的区别：`async` 是「谁先下载完谁先执行」，不保证顺序；`defer` 保证按书写顺序执行。有依赖关系时（`app.js` 用到 `api.js`）必须用 `defer`。

### 基本语法

#### 变量

在 JavaScript 中，使用 `var`、`let` 或 `const` 关键字声明变量：

```js
var x; // 声明一个变量x
let y = 5; // 声明一个变量y并初始化为5
const PI = 3.14; // 声明一个常量PI，并初始化为3.14
```

#### 数据类型

JavaScript 有一些基本的数据类型：

- `字符串（String）`： 用于表示文本。
- `数字（Number）`： 用于表示数值。
- `布尔值（Boolean）`： 用于表示真（true）或假（false）。
- `未定义（Undefined）`： 表示变量声明但未初始化。
- `空值（Null）`： 表示空或无值。

```js
var greeting = "Hello, World!";
var age = 25;
var logic = true;
var z;
var empty_value = null;
```

#### 条件

条件语句是编程中常用的结构，用于基于不同的条件执行不同的代码块。在 JavaScript 中，条件语句主要包括 if、else if 和 else。下面详细讲解条件语句的使用：

1. `if 语句`：用于执行一个代码块，当指定的条件为真（true）时执行。语法如下：

```js
if (condition) {
    // 如果条件为真，执行这里的代码
}

// 示例
// 这个例子中，如果 age 大于或等于 18，就会输出 "你已经成年了。"。
var age = 18;

if (age >= 18) {
    console.log("你已经成年了。");
}
```

2. `else` 语句：用于在上一个 if 和所有的 else if 都为假时执行的代码块。语法如下：

```js
if (condition) {
    // 如果条件为真，执行这里的代码
} else {
    // 如果条件为假，执行这里的代码
}

// 示例
// 在这个例子中，如果 is_raining 为真，输出 "记得带伞！"，否则输出 "天气不错，无需带伞。"。

var is_raining = true;

if (is_raining) {
    console.log("记得带伞！");
} else {
    console.log("天气不错，无需带伞。");
}
```

3. `else if` 语句：用于在上一个 if 语句条件为假时，检查另一个条件。可以有多个 else if 语句。语法如下：

```js
if (condition1) {
    // 如果条件1为真，执行这里的代码
} else if (condition2) {
    // 如果条件2为真，执行这里的代码
} else {
    // 如果以上条件都为假，执行这里的代码
}

// 示例
// 在这个例子中，根据不同的时间，会输出不同的问候语。
var time = 14;

if (time < 12) {
    console.log("上午好！");
} else if (time < 18) {
    console.log("下午好！");
} else {
    console.log("晚上好！");
}
```

条件语句可以嵌套在其他条件语句中，形成嵌套结构。这种结构允许根据多个条件的组合来执行不同的代码块，代码如下：

```js
var score = 85;

if (score >= 90) {
    console.log("优秀！");
} else {
    if (score >= 80) {
        console.log("良好！");
    } else {
        console.log("一般！");
    }
}
```

根据不同的情况执行不同的代码，从而实现更灵活的程序逻辑。

#### 循环

循环语句用于重复执行一段代码，直到指定的条件不再满足为止。在 JavaScript 中，常见的循环语句有 `for` 循环、`while` 循环和 `do...while` 循环。下面详细讲解这些循环语句的使用：

1. `for` 循环：是一种常见的循环结构，用于按照指定的条件重复执行代码块。语法如下：

```js
for (初始化表达式; 循环条件; 迭代器) {
    // 循环体，执行这里的代码
}

// 示例
// 在这个例子中，var i = 0 是初始化表达式，
// i < 5 是循环条件，i++ 是迭代器。循环体中的代码会被执行5次，输出0到4。
for (var i = 0; i < 5; i++) {
    console.log(i); // 输出 0 到 4
}
```

2. `while` 循环会在指定的条件为真时执行代码块。语法如下：

```js
while (循环条件) {
    // 循环体，执行这里的代码
}

// 示例
// 在这个例子中，i < 5 是循环条件，
// 循环体中的代码会在每次循环时执行，输出0到4。
var i = 0;
while (i < 5) {
    console.log(i); // 输出 0 到 4
    i++;
}
```

3. `do...while` 循环会先执行一次代码块，然后检查指定的条件是否为真，如果为真，则重复执行。语法如下：

```js
do {
    // 循环体，执行这里的代码
} while (循环条件);
// 示例
// 在这个例子中，循环体中的代码会至少执行一次，
// 然后在每次循环时检查条件是否为真，如果为真，则继续执行。
var i = 0;

do {
    console.log(i); // 输出 0 到 4
    i++;
} while (i < 5);
```

在循环中，可以使用 `break` 和 `continue` 来控制循环的流程：

- `break` 用于跳出循环，**结束循环的执行**。
- `continue` 用于跳过当前循环中的剩余代码，**继续下一次循环**。

```js
for (var i = 0; i < 5; i++) {
    if (i === 2) {
        continue; // 跳过 i 等于 2 的情况
    }
    if (i === 4) {
        break; // 结束循环，跳出循环体
    }
    console.log(i);
}
```

循环语句是控制程序重复执行的重要工具，合理使用循环可以使代码更加简洁高效。

#### 函数

函数是一段可重复使用的代码块，它接受输入（参数）、执行特定任务，并返回输出。在 JavaScript 中，函数是一等公民，可以**被赋值给变量**，作为参数传递给其他函数，也可以作为其他函数的返回值。
使用 `function` 关键字声明一个函数，语法如下：

```js
function function_name(参数) { // 参数可以不写，表示不传参
    // 函数体，执行这里的代码
    return 返回值; // 可选，返回值
}

// 示例
function greet() {
    console.log("Hello, world!");
}

// 有返回值的函数
function greet_with_return() {
    return "Hello, world!";
}
```

通过函数名和括号调用函数，将参数传递给函数：

```js
greet();

var a = greet_with_return()
console.log(a);
```

函数可以接受零个或多个参数，参数是函数在执行时的输入。参数由逗号分隔，定义在函数声明中。示例：

```js
function greet_with_param(name) {
    return "Hello, " + name + "!";
}

// 调用
var greeting = greet_with_param("Alice");
console.log(greeting); // 输出：Hello, Alice!
```

`匿名函数` 是没有函数名的函数，通常用于作为函数表达式，或在函数内定义一个函数。示例：

```js
var square = function (x) {
    return x * x;
};
```

JavaScript 中的作用域分为 `全局作用域` 和 `局部作用域`。在函数内部声明的变量具有函数作用域，而在函数外部声明的变量具有全局作用域。

```js
var globalVar = "I am global";

function example() {
    var localVar = "I am local";
    console.log(globalVar); // 可访问全局变量
    console.log(localVar); // 可访问局部变量
}

example();
console.log(globalVar); // 输出：I am global
console.log(localVar); // 报错，局部变量不可在函数外部访问
```

闭包是指一个函数能够访问并记住其词法作用域，即使该函数在当前词法作用域之外执行。闭包使得函数可以保持对其创建时的作用域的引用。示例：

```js
function outer() {
    var outerVar = "I am outer";

    function inner() {
        console.log(outerVar); // 访问了外部函数的变量
    }

    return inner;
}

var closureFunc = outer();//这里的 outerVar 就已经被销毁了
closureFunc(); // 输出：I am outer
```

特征：

1. 函数嵌套函数（外层包内层）
2. 内层函数访问外层函数的变量
3. 外层函数把内层函数返回出去（或传递出去）

### 事件

JavaScript 中的事件处理是前端开发中至关重要的一部分，它允许你对用户的交互做出响应，例如点击、鼠标移动、键盘输入等。
事件是文档或浏览器窗口中发生的特定瞬间，例如用户的点击、键盘的按下、页面的加载等。常见的事件如下：

| 事件                                                                                                                                     | 描述             |
| ---------------------------------------------------------------------------------------------------------------------------------------- | ---------------- |
| `onClick`                                                                                                                              | 点击事件         |
| `onMouseOver`                                                                                                                          | 鼠标经过         |
| `onMouseOut`                                                                                                                           | 鼠标移出         |
| `onChange`                                                                                                                             | 文本内容改变事件 |
| `onSelect`                                                                                                                             | 文本框选中       |
| `onFocus`                                                                                                                              | 光标聚集         |
| `onBlur`                                                                                                                               | 移开光标         |
| `onLoad`                                                                                                                               | 网页加载         |
| `onUnload`                                                                                                                             | 关闭网页         |
| **事件处理程序是与特定事件相关联的函数**。当事件发生时，关联的事件处理程序将被调用。在 HTML 中，可以通过以下方式添加事件处理程序： |                  |

1. `HTML` 属性：

```html
<button onclick="myFunction()">Click me</button>
```

2. `DOM` 属性：

```js
var button = document.getElementById('myButton');
button.onclick = function () {
    alert('Button clicked!');
};
```

3. `addEventListener` 方法，比较先进：

```js
var button = document.getElementById('myButton');
button.addEventListener('click', function () {
    alert('Button clicked!');
});
```

### DOM操作

现在，已经学会了 JavaScript 的基础语法了，那怎样才能让 JavaScript 与 HTML、CSS 结合在一起呢？这时候我们就需要用到 JavaScript 中的 DOM（文档对象模型），它操作允许开发者通过 JavaScript 与 HTML 文档交互，动态地改变文档的结构、样式和内容。
当网页被加载时，浏览器会创建页面的文档对象模型，也就是 DOM（Document Object Model）

> 提示
> 如果不理解什么是对象也没关系，只需要知道对象的作用就是让函数和变量之前建立关系，对象中的属性就是变量，方法就是函数。与普通的变量、函数相比，区别就是在调用的使用前面需要加对象名

在 Web 开发中，DOM 通常与 JavaScript 一起使用。每个 HTML 或 XML 文档都可以被视为一个文档树，文档树是整个文档的层次结构表示。每个节点都有父节点、子节点和同级节点。文档节点是整个文档树的根节点，而其他节点则分布在树的不同层次上。DOM 为这个文档树提供了一个编程接口，开发者可以使用 JavaScript 来操作这个树状结构。
![](https://gcore.jsdelivr.net/gh/bigrich-luo/typora-picgo-images-1@master/images/202311271639468.png)
DOM 中的一切都是节点。文档本身是一个文档节点，而文档中的元素、属性和文本都是不同类型的节点。主要的节点类型包括：

1. `元素节点（Element Nodes）`： 表示 HTML 或 XML 文档中的元素，如 `<div>`、`<p>` 等。
2. `属性节点（Attribute Nodes）`： 表示元素的属性，如 class、id 等。
3. `文本节点（Text Nodes）`： 表示元素的文本内容。

首先，如果我们想要在 JavaScript 中获取 HTML、CSS 节点，也就是元素，就需要使用一些 DOM API 提供的方法来获取文档中的元素。常见的方法包括：

1. `getElementById`： 通过元素的 ID 获取元素。

```js
var element = document.getElementById('myElement');
```

2. `getElementsByClassName`： 通过类名获取元素，U class 有可能有很多个，所以后面可以加上索引，浏览器返回的也是数组，查一下到底索引是多少，以便更好的确认自己需要的是什么。

```js
var elements = document.getElementsByClassName('myClass')[0];
```

3. `getElementsByTagName`： 通过标签名获取元素。

```js
var paragraphs = document.getElementsByTagName('p');
```

一旦获取了元素，你就可以通过 DOM 提供的方法来操作它。例如，你可以改变元素的样式、修改其文本内容、添加或删除子元素等。

```js
// 修改元素文本内容
element.innerHTML = '新的文本内容';

// 添加新的子元素
var newElement = document.createElement('div');
element.appendChild(newElement);

// 移除子元素
var childElement = element.firstChild;
element.removeChild(childElement);
```

这里列举一些常用的 DOM 对象方法：

| 方法                                                  | 描述                                                            |
| ----------------------------------------------------- | --------------------------------------------------------------- |
| `getElementById()`                                  | 返回带有指定 ID 的元素。                                        |
| `getElementsByTagName()`                            | 返回包含带有指定标签名称的所有元素的节点列表（集合/节点数组）。 |
| `getElementsByClassName()`                          | 返回包含带有指定类名的所有元素的节点列表。                      |
| `appendChild()`                                     | 把新的子节点添加到指定节点。                                    |
| `removeChild()`                                     | 删除子节点。                                                    |
| `replaceChild()`                                    | 替换子节点。                                                    |
| `insertBefore()`                                    | 在指定的子节点前面插入新的子节点。                              |
| `createAttribute()`                                 | 创建属性节点。                                                  |
| `createElement()`                                   | 创建元素节点。                                                  |
| `createTextNode()`                                  | 创建文本节点。                                                  |
| `getAttribute()`                                    | 返回指定的属性值。                                              |
| `setAttribute()`                                    | 把指定属性设置或修改为指定的值。                                |
| 你可以通过 DOM 修改元素的样式，例如改变颜色、大小等。 |                                                                 |

```js
// 修改元素样式
element.style.color = 'red';
element.style.fontSize = '20px';
```

通过 DOM，你可以**监听和响应**用户的交互事件，例如点击、输入等。这使得你能够创建交互性更强的页面。

```js
// 监听点击事件
element.addEventListener('click', function () {
    console.log('元素被点击了！');
});
```

最后，是一个简单的案例，演示如何通过 JavaScript 来进行表格的增删改查操作。

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>CRUD Table Example</title>
    <style>
        table {
            border-collapse: collapse;
            width: 100%;
            margin-top: 20px;
        }

        th, td {
            border: 1px solid #ddd;
            padding: 8px;
            text-align: left;
        }

        th {
            background-color: #f2f2f2;
        }

        button {
            margin-top: 10px;
        }
    </style>
</head>
<body>
    <h2>CRUD Table Example</h2>
    <button onclick="addRow()">Add Row</button>
    <table id="dataTable">
        <thead>
            <tr>
                <th>Name</th>
                <th>Email</th>
                <th>Action</th>
            </tr>
        </thead>
        <tbody>
            <tr>
                <td>John Doe</td>
                <td>john@example.com</td>
                <td>
                    <button onclick="editRow(this)">Edit</button>
                    <button onclick="deleteRow(this)">Delete</button>
                </td>
            </tr>
            <!-- Additional rows will be added dynamically -->
        </tbody>
    </table>

    <script src="./js/script.js"></script>
</body>
</html>
```

```js
function addRow() {
    var table = document.getElementById("dataTable");
    var newRow = table.insertRow(table.rows.length);

    var nameCell = newRow.insertCell(0);
    var emailCell = newRow.insertCell(1);
    var actionCell = newRow.insertCell(2);

    nameCell.innerHTML = "New User";
    emailCell.innerHTML = "newuser@example.com";
    actionCell.innerHTML = '<button onclick="editRow(this)">Edit</button>' +
                           '<button onclick="deleteRow(this)">Delete</button>';
}

function editRow(button) {
    var row = button.parentNode.parentNode;
    var nameCell = row.cells[0];
    var emailCell = row.cells[1];

    var newName = prompt("Enter new name", nameCell.innerHTML);
    var newEmail = prompt("Enter new email", emailCell.innerHTML);

    if (newName !== null && newEmail !== null) {
        nameCell.innerHTML = newName;
        emailCell.innerHTML = newEmail;
    }
}

function deleteRow(button) {
    var row = button.parentNode.parentNode;
    row.parentNode.removeChild(row);
}
```

总体而言，DOM 提供了一个强大的工具集，使得开发者可以使用脚本语言动态地操作和更新网页。通过合理利用 DOM，你可以创建出更灵活、交互性更强的用户界面。

### 现代 DOM 选择：`querySelector` / `querySelectorAll`

**结论**：`getElementById` 只能按 id 取单个元素；`querySelector` 直接吃 CSS 选择器语法（和 CSS 笔记里那套完全一致），返回**第一个**匹配的元素；`querySelectorAll` 返回**所有**匹配元素（NodeList）。日常 DOM 取值基本用这两个就够了。

```js
const sendBtn = document.querySelector('#send');                  // id 选择器
const delBtns = document.querySelectorAll('.conversation .del');  // 后代选择器
const firstLi = document.querySelector('ul > li');                // 子元素选择器
```

> `querySelectorAll` 返回的 NodeList 不是真数组：可以用 `forEach` 遍历，但想用 `map` / `filter` 得先 `Array.from(delBtns)`。

### 改样式：切 class 优先于 `element.style`

**结论**：`element.style.color = 'red'` 写的是**内联样式**，散落在 JS 里难维护。工程上更常见的是「**切 class，样式留在 CSS 里**」——用 `classList.add / remove / toggle / contains`。原生方案里「切页面」「切会话」就是靠它，配合 CSS 的 `display: none`。

HTML：

```html
<div id="login-page" class="page">登录页</div>
<div id="chat-page" class="page hidden">聊天页</div>
```

CSS：

```css
.hidden { display: none; }
```

JS：

```js
const loginPage = document.querySelector('#login-page');
const chatPage = document.querySelector('#chat-page');

// 登录成功后：隐藏登录页，显示聊天页
loginPage.classList.add('hidden');
chatPage.classList.remove('hidden');

// 切换显示 / 隐藏（有就删、没有就加）
document.querySelector('#status').classList.toggle('hidden');
```

### `textContent` 与 `innerHTML` 的分工

**结论**：

- `textContent`：**默认选择**。把字符串当纯文本，不解析 HTML，天然防注入。
- `innerHTML`：把字符串当 HTML **解析**——能渲染标签，同时也是 XSS 入口。只有需要渲染富文本 / Markdown 时才用，且必须先过 `DOMPurify.sanitize`。
- `input.value`：读输入框当前内容；写入空串就是清空。
- `button.disabled = true`：禁用按钮，用来实现「生成中禁用发送」。

```js
const input = document.querySelector('#msg-input');
const sendBtn = document.querySelector('#send');

input.value = '';          // 清空输入框
sendBtn.disabled = true;   // 生成中：禁用
sendBtn.disabled = false;  // 生成完：恢复

// 纯文本 → textContent（推荐）
bubble.textContent = '你好';
// 需要渲染 Markdown 时 → innerHTML，且必须先净化
bubble.innerHTML = DOMPurify.sanitize(marked.parse(aiText));
```

### 数组方法：`map` / `filter` / `find` / `join` / `push`

**结论**：渲染列表的标准写法是——`map` 把「数据数组」映射成「HTML 字符串数组」，再 `join('')` 拼成一整块塞进容器。删一条 = `filter` 出「不包含它」的新数组。

```js
const list = document.querySelector('#conv-list');

// 数据 → HTML 字符串
function renderConversations(convs) {
    list.innerHTML = convs
        .map(c => `<li data-id="${c.id}">${c.title}</li>`)
        .join('');
}

let convs = [{ id: 1, title: 'a' }, { id: 2, title: 'b' }];

convs = convs.filter(c => c.id !== 2);  // 删掉 id 为 2 的那条

const target = convs.find(c => c.id === 1);  // 找出第一个满足条件的元素
convs.push({ id: 3, title: 'c' });           // 往数组尾部追加
```

> 各方法速记：`map` 一对一转换；`filter` 筛选出子集；`find` 找第一个（返回元素本身，找不到返回 `undefined`）；`join('')` 把数组拼成字符串（分隔符传空串即无缝拼接）；`push` 改原数组。

### 模板字符串（`` `${}` ``）

**结论**：用反引号包字符串，里面用 `${}` 插值。拼 HTML 比 `+` 可读得多，而且能直接换行。

```js
const html = `
    <div class="bubble">
        <p class="role">${msg.role}</p>
        <div class="content">${msg.content}</div>
    </div>
`;
```

> ⚠️ **安全提醒**：凡是「把数据拼进 HTML 字符串」，都是 XSS 入口。用户输入、模型输出直接拼进 `innerHTML` 有被注入脚本的风险，渲染富文本时要过 `DOMPurify`。

### 事件对象与 `preventDefault`

**结论**：事件处理函数会收到一个**事件对象** `event`，三个最常打交道的成员：

- `event.target.value`：取触发事件的输入框当前内容；
- `event.preventDefault()`：阻止默认行为（表单默认提交会刷新页面、状态全丢；链接默认跳转）；
- `event.key === 'Enter'`：判断按了哪个键（回车发送）。

HTML：

```html
<form id="login-form">
    <input id="username" type="text" placeholder="用户名">
    <button type="submit">登录</button>
</form>
```

JS：

```js
document.querySelector('#login-form').addEventListener('submit', (event) => {
    event.preventDefault();  // 关键：阻止表单默认提交，否则页面刷新、状态丢光
    const username = document.querySelector('#username').value;
    login(username);
});

// 输入框里回车发送
document.querySelector('#msg-input').addEventListener('keydown', (event) => {
    if (event.key === 'Enter') sendMessage();
});
```

### HTTP 请求常识与请求头

**结论**：调接口就是把「**方法 + URL + 请求头 + 请求体**」凑齐。原来的表单那节只讲了 GET / POST 的区别，实际对接后端还要懂请求头与状态码。

常用请求头：

| 请求头                                              | 用途                                          |
| --------------------------------------------------- | --------------------------------------------- |
| `Authorization: Bearer <token>`                   | 携带身份凭证                                  |
| `Content-Type: application/json`                  | 声明请求体是 JSON                             |
| `Content-Type: application/x-www-form-urlencoded` | 声明请求体是表单（OAuth2 的登录接口要求这种） |

常见状态码语义：

| 状态码 | 含义                             | 前端该做什么         |
| ------ | -------------------------------- | -------------------- |
| 401    | 未认证                           | 清 token、跳回登录页 |
| 404    | 资源不存在（越权访问也返回 404） | 提示不存在           |
| 409    | 冲突                             | 如「用户名已存在」   |
| 422    | 参数校验失败                     | 提示表单有误         |
| 502    | 上游服务失败                     | 提示稍后重试         |

**最容易踩的点**：同一个登录页上，**注册发 JSON、登录发表单**（OAuth2 规范要求登录用表单）。用 `URLSearchParams` 拼表单 body：

```js
// 注册：JSON 请求体
await fetch('/api/v1/auth/register', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ username, password }),
});

// 登录：表单请求体
const form = new URLSearchParams();
form.append('username', username);
form.append('password', password);
await fetch('/api/v1/auth/login', {
    method: 'POST',
    headers: { 'Content-Type': 'application/x-www-form-urlencoded' },
    body: form,
});
```

### `fetch` + `Promise` + `async/await`

**结论**：`fetch` 发请求，返回一个 **Promise**（「将来才有结果」的容器）。用 `await` 拿结果要**两次**：

1. 第一次 `await fetch(...)` 拿到的是**响应对象** `Response`；
2. 第二次 `await res.json()` 才真正读到数据。

**反直觉点（重点）**：`fetch` 对 401 / 500 **不会报错**，它只在网络断掉（断网、域名解析失败）时才 reject。所以 HTTP 层面的失败必须自己用 `res.ok` 判断。`async` 函数一定返回 Promise；`await` 只能在 `async` 函数里用。

```js
async function getConversations() {
    const res = await fetch('/api/v1/conversations', {
        headers: { Authorization: `Bearer ${token}` },
    });
    if (!res.ok) {
        throw new Error(`HTTP ${res.status}`);  // 必须自己判断，fetch 不会帮你抛
    }
    const json = await res.json();  // 第二次 await 才拿到数据
    return json.data;
}
```

### `try/catch` 与错误处理

**结论**：既然 `fetch` 不帮你抛 HTTP 错误，「接口失败」就有**两条路径**要分开处理：

- **网络错误 / 代码异常** → 走 `catch`（断网、`res.json()` 解析失败等）；
- **业务错误** → 走 `!res.ok`，再读后端统一信封里的 `code` / `message`。

```js
try {
    const res = await fetch('/api/v1/auth/login', { method: 'POST', body: form });

    if (!res.ok) {
        // 业务错误：后端返回统一信封 { code, message }
        const err = await res.json();
        if (res.status === 401) {
            localStorage.removeItem('token');
            location.reload();   // 跳回登录
            return;
        }
        alert(err.message || `请求失败 (${res.status})`);
        return;
    }

    const json = await res.json();
    // 使用 json.data ...
} catch (e) {
    // 网络错误、代码异常
    alert('网络异常，请稍后重试');
}
```

### `JSON.parse` / `JSON.stringify` 与 `localStorage`

**结论**：`localStorage` **只能存字符串**，所以存对象要 `JSON.stringify` 序列化，取出来要 `JSON.parse` 反序列化。token 和用户信息存这里，实现「刷新页面不掉登录」。

```js
// 存
localStorage.setItem('token', token);                  // 字符串直接存
localStorage.setItem('user', JSON.stringify(user));    // 对象先序列化

// 取
const token = localStorage.getItem('token');
const user = JSON.parse(localStorage.getItem('user') || 'null');

// 删（退出登录）
localStorage.removeItem('token');
localStorage.removeItem('user');
```

### 对象字面量、解构、展开 `...`

**结论**：从 JSON 里取字段用**解构**；复制 / 合并数组、对象用**展开运算符 `...`**。

```js
const user = { id: 1, name: 'Bob', role: 'admin' };

// 解构取值
const { id, name } = user;
// 解构时改名 / 给默认值
const { name: userName, email = '未填写' } = user;

// 展开：浅拷贝一份再改，不动原对象
const next = { ...user, role: 'user' };
// 展开：往数组尾部追加
const list2 = [...list, newItem];
```

### `var` / `let` / `const` 的作用域差异 + `for` 循环的闭包坑

**结论**：`var` 没有块级作用域（是函数级 / 全局），`let` / `const` 有块级作用域。这是「为什么要用 `let`」最有说服力的一条：

```js
// var：所有回调共享同一个 i，循环结束后 i 已经是 3
for (var i = 0; i < 3; i++) {
    btns[i].onclick = () => console.log(i);  // 三个按钮都打印 3
}

// let：每次迭代都是一个全新的 i
for (let i = 0; i < 3; i++) {
    btns[i].onclick = () => console.log(i);  // 0 1 2，符合预期
}
```

> 顺带澄清：`const` 只是「不能再重新赋值」，对象 / 数组的内容仍然可以改。

```js
const arr = [1];
arr.push(2);   // 可以，改的是内容
arr = [];      // 报错，不能重新赋值
```

### `dataset`：给元素挂数据（`data-*`）

**结论**：要给列表里的按钮标记「我对应哪个 id」，用 HTML 的 `data-*` 属性，JS 里用 `dataset` 读，比到处传变量干净。

HTML：

```html
<button class="del" data-id="3">删除</button>
```

JS：

```js
document.querySelectorAll('.del').forEach((btn) => {
    btn.addEventListener('click', () => {
        const id = btn.dataset.id;  // "3"，注意是字符串
        deleteConversation(Number(id));
    });
});
```

### 自动滚到底：`scrollTop` / `scrollHeight`

**结论**：聊天窗必备——新消息在视野之外，用户会以为没反应。渲染完消息后把滚动条拉到底：

```js
const box = document.querySelector('#messages');
box.scrollTop = box.scrollHeight;  // 滚到最底
```

三个量的关系：`scrollHeight` 是内容总高度，`clientHeight` 是可视区高度，`scrollTop` 是当前滚动位置。前提是容器有 `overflow-y: auto`（见 CSS 笔记）。
